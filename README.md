# 올인원 이미지/PDF 유틸리티

설치 없이 브라우저에서 바로 사용할 수 있는 이미지·PDF 변환 및 편집 도구입니다.  
모든 처리는 **사용자의 브라우저에서 로컬로** 수행되며, 파일이 외부 서버로 전송되지 않아 보안이 완벽하게 보장됩니다.

- **실행 사이트**: [https://diet33.github.io/image-pdf-utils/](https://diet33.github.io/image-pdf-utils/)
- **PWA 오프라인 지원**: 인터넷 연결이 없어도 브라우저 캐시로 즉시 동작합니다.

---

## 주요 기능 안내

| 탭 / 기능 | 설명 |
|-----------|------|
| 🖼️ **사진 보기 (갤러리)** | **내 컴퓨터(파일/폴더 통째로 열기)**, **구글 드라이브(내 드라이브 링크 및 탐색기)**, 모바일 파일앱 사진을 불러와 썸네일·슬라이드로 감상 및 전체 ZIP 다운로드 |
| 📄 **PDF → JPG** | PDF의 각 페이지를 JPG로 변환. **특정 페이지 범위 선택 추출(예: 1-3, 5)** 지원 |
| 📑 **이미지 → PDF** | 여러 장의 이미지를 순서대로 묶어 **하나의 PDF 문서로 생성** (순서 변경, A4/여백/방향 설정) |
| 📐 **이미지 줄이기** | 50/20/10% 비율 외에 **사용자 지정 %(비율)**, **특정 해상도(px)**, **목표 파일 용량(KB)** 맞춤 축소 |
| ⚡ **포맷 변환·압축** | WebP / JPG / PNG 상호 변환 및 초경량 압축 + **개인정보/EXIF 메타데이터(GPS 위치/촬영정보) 완전 삭제** |
| 🔍 **이미지 2배 확대** | pica Lanczos 필터 기반 고품질 2배 업스케일 |
| 📋 **이미지 합치기** | 여러 이미지를 **세로(위→아래)** 또는 **가로(좌→우)**로 이어붙이기 (드래그/버튼으로 순서 재정렬) |
| ✂️ **이미지 편집** | **90도 좌/우 회전**, **좌우/상하 반전**, **영역 자르기(Crop)**, 밝기·대비·채도 조절 |
| 📷 **문서 스캔 보정** | OpenCV.js로 문서 영역 자동 감지 + **화면 위에서 4개 모서리 꼭짓점을 터치/드래그하여 미세조정** |
| 🌓 **다크 모드** | 눈의 피로를 덜어주는 라이트 / 다크 테마 지원 |

## 사용 방법 상세

### 1. 사진 보기 (내 컴퓨터 & 구글 드라이브 연동)
- **내 컴퓨터 폴더 통째로 열기**: `📂 내 컴퓨터 폴더 통째로 열기` 버튼을 누르면 폴더 안의 모든 사진을 한 번에 로드합니다.
- **구글 드라이브 연동**: `☁️ 구글 드라이브 (내 드라이브)` 버튼을 누르고,
  - **방법 1 (가장 간편)**: 구글 드라이브 공유 링크(공개 링크)를 입력하여 즉시 사진을 불러옵니다.
  - **방법 2**: Google Client ID / API Key를 입력하여 내 드라이브 파일 탐색기를 직접 열어 사진을 선택합니다.
- **슬라이드쇼**: 썸네일을 탭하거나 `슬라이드 보기`를 눌러 전체화면에서 스와이프 또는 방향키로 넘겨봅니다.

### 2. PDF → JPG (페이지 범위 지정)
- PDF 파일을 업로드합니다.
- `변환할 페이지 범위` 입력란에 원하는 페이지를 입력합니다.
  - 예: 비워둠 (모든 페이지)
  - 예: `1-3, 5` (1, 2, 3, 5 페이지만 추출)
- 변환 후 개별 다운로드 또는 `전체 ZIP 다운로드`를 실행합니다.

### 3. 이미지 → PDF 변환
- 이미지들을 업로드합니다.
- 아래 목록에서 `▲` / `▼` 버튼을 누르거나 드래그하여 PDF에 들어갈 순서를 변경합니다.
- 용지 크기(A4, 원본 크기, Letter), 방향(자동, 세로, 가로), 여백을 설정합니다.
- `PDF 문서 생성`을 누르면 하나의 PDF 파일로 다운로드됩니다.

### 4. 이미지 줄이기 (맞춤형 축소)
- **프리셋 비율**: 50%, 20%, 10%, 75%, 30% 중 선택
- **직접 비율(%)**: 원하는 퍼센트(예: 65%)를 직접 입력
- **특정 해상도(px)**: 가로 또는 세로 기준 원하는 픽셀(예: 1200px) 입력 (종횡비 자동 유지)
- **목표 파일 용량(KB)**: 목표 용량(예: 300KB)을 지정하면 브라우저가 최적의 해상도와 압축률을 자동으로 찾아 압축합니다.

### 5. 포맷 변환 & 초경량 압축 + EXIF 제거
- WebP, JPG, PNG 중 원하는 포맷과 압축 품질(10~100%)을 선택합니다.
- `개인정보(EXIF) 메타데이터 완전 제거`가 기본 적용되어 스마트폰 촬영 위치(GPS)나 기기 정보가 안전하게 삭제됩니다.
- 원본 크기 대비 절감률(예: `-82%`)을 실시간으로 확인하고 다운로드합니다.

### 6. 이미지 합치기 (세로 / 가로 + 순서 변경)
- 2장 이상의 이미지를 선택합니다.
- 목록에서 순서를 자유롭게 조정합니다.
- `세로로 이어붙이기` 또는 `가로로 이어붙이기`를 선택합니다.
- 기준 크기(첫 번째 이미지 기준, 최대 기준, 직접 입력 px)를 설정하고 합치기를 실행합니다.

### 7. 간단 이미지 편집
- 편집할 이미지를 선택합니다.
- `↺ 90° 좌회전`, `↻ 90° 우회전`, `↔️ 좌우 반전`, `↕️ 상하 반전`
- `📐 자르기(크롭)`: 마우스나 터치로 원하는 영역을 선택 후 `✔️ 자르기 적용`
- 밝기, 대비, 채도 슬라이더로 색감 보정 후 바로 저장합니다.

### 8. 문서 스캔 보정 (4점 꼭짓점 수동 미세조정)
- 스마트폰 카메라 촬영 또는 앨범 사진을 불러옵니다.
- 화면에 표시되는 **4개의 둥근 모서리 점을 손가락이나 마우스로 드래그**하여 문서 테두리에 정밀하게 맞춥니다.
- 컬러 모드(선명화·대비 보정) 또는 흑백 모드(복사본 스타일)를 선택하고 `보정 실행`을 누릅니다.

## GitHub Pages 배포 방법

### 원클릭 배포 (Windows)
```cmd
deploy.bat
```
또는 PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1
```

### Git 명령어로 직접 배포
```bash
git add .
git commit -m "Update all features: Google Drive, Image-to-PDF, Editor, Reorder, etc."
git push origin main
```
저장소의 GitHub Actions 워크플로우를 통해 1~2분 내에 GitHub Pages에 자동 반영됩니다.
